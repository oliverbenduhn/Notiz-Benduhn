# Notiz-Benduhn

Eine einzelne, von allen Nutzer:innen gemeinsam bearbeitete Notiz.

## Language

**Note synchronization**:
Der Abgleich zwischen dem lokalen Bearbeitungsstand einer geteilten Notiz und ihrem gespeicherten Stand, einschließlich ausstehender Änderungen und konkurrierender Änderungen.
_Avoid_: Autosave, polling logic, sync state

**Editor command**:
Eine benannte Bearbeitungsaktion der gemeinsamen Notiz, die über Toolbar und Slash-Menü erreichbar ist.
_Avoid_: toolbar action, slash command
